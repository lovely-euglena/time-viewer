


# TimeDisplay

一款功能丰富的 Windows 桌面时间显示应用程序，支持 NTP 网络时间同步、全屏模式等多种功能。

## 功能特点

- **时间显示**：实时显示当前时间和日期
- **NTP 时间同步**：支持通过网络时间协议自动同步系统时间，内置多个 NTP 服务器
- **全屏模式**：支持全屏显示，适合用于时钟展示或大屏显示
- **触摸支持**：支持触摸操作，可用于触摸屏设备
- **DPI 感知**：支持高 DPI 显示，确保在不同分辨率下清晰显示
- **动态字体**：根据窗口大小自动调整字体大小

## 系统要求

- Windows 7 或更高版本
- Visual Studio 2015 或更高版本
- Windows SDK

## 构建说明

1. 使用 Visual Studio 打开 `TimeDisplay.sln` 文件
2. 选择合适的配置（Debug/Release）和平台（x86/x64）
3. 按 Ctrl+Shift+B 或选择"生成解决方案"

## 使用说明

- **全屏按钮**：点击按钮切换全屏模式
- **同步按钮**：手动同步 NTP 时间
- **ESC 键**：退出全屏模式
- **双击窗口标题栏**：进入全屏模式

## 项目结构

- `main.cpp` - 主程序逻辑，包含窗口创建和时间显示
- `ntp_client.cpp/h` - NTP 客户端实现，用于网络时间同步
- `fullscreen.cpp/h` - 全屏模式管理
- `resource.h` - 资源定义

## 技术栈

- Win32 API
- C++11 (多线程、原子操作)
- NTP 协议
- Windows Socket
